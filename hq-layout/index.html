확정 전 확인 사항

  1. 1층 상주(채권관리·GA)에 대한 업체 의견 확인 필요. 업체는 낮은 천고와 네트워크 미비를 지적했으므로 AP·LED·프레임 철거로 보완 가능한지 확인해야 함.
  2. IT가 G층, 서버실이 2층에 있어 서버실 출입 동선과 보안 기준을 IT 담당과 확인 필요.
  3. G층 우측 회색 구역(KB Bank 대여금고 구역으로 추정)과 5층 좌측 구역의 범위·용도 확인 필요. 사용 가능하면 증원 여력이 생김.
  4. 심사의 보고 라인(CEO 직할 여부), 인사·Corsec 분리 후 인원(인사 3, Corsec 2로 반영)과 부서장 지정은 조직 확정 시 조정 필요.
  5. 부서별 인원은 9/11 조직정보와 8월 배치도 기준 추정치임. 업체 송부 전 인사팀 명부로 대사 필요.
  6. 주 통로 폭(1.2~1.3m)과 피난 동선은 현지 건축·소방 기준으로 업체가 확인해야 함.
